How Fallow Analyzes TypeScript in Under a Second

Fallow is a codebase analyzer written in Rust for TypeScript and JavaScript projects, created by Bart Waardenburg. I contribute to it, and my pull requests are where most of this understanding came from. It finds unused files, dead exports, unlisted dependencies, code duplication, circular dependencies, and complexity hotspots. It’s a Rust alternative to Knip.
