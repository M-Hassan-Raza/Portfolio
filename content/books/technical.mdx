### <span className="book-subtitle">Database Internals: A Deep Dive into How Distributed Data Systems Work</span>
<div className="book-cover">
  <AsciiCover asset="designing-db-internals" alt="Database Internals Cover" variant="portrait" />
</div>
<p className="author">Author: Alex Petrov</p>
<blockquote className="review">
A comprehensive guide to the internal workings of distributed data systems. Covers <strong>storage engines, replication, and consensus algorithms</strong> like <strong>Raft and Paxos</strong>. A must-read for anyone working with databases. Since I'm big on databases, this was a no-brainer.
</blockquote>

### <span className="book-subtitle">Designing Data-Intensive Applications</span>
<div className="book-cover">
  <AsciiCover asset="designing-data-intensive-applications" alt="Designing Data-Intensive Applications Cover" variant="portrait" />
</div>
<p className="author">Author: Martin Kleppmann</p>
<blockquote className="review">
It's all about data these days. It's the new <strong>elixir of life</strong>. Covers <strong>OLTP vs. OLAP, distributed databases, caching strategies, event-driven architectures, and stream processing</strong>. If you don't understand this stuff, you're missing out.
</blockquote>

### <span className="book-subtitle">Crafting Interpreters</span>
<div className="book-cover">
  <AsciiCover asset="crafting-interpreters" alt="Crafting Interpreters Cover" variant="portrait" />
</div>
<p className="author">Author: Robert Nystrom</p>
<blockquote className="review">
Most don't care about how their code gets executed, but they should. This book takes you from <strong>lexing, parsing, and ASTs</strong> to building a full interpreter from scratch. Writing a line that looks like English and making it do things is pure magic. Every programmer should go through that <strong>euphoric feeling</strong> at least once.
</blockquote>

### <span className="book-subtitle">Clean Code: A Handbook of Agile Software Craftsmanship</span>
<div className="book-cover">
  <AsciiCover asset="cleancode" alt="Clean Code Cover" variant="portrait" />
</div>
<p className="author">Author: Robert C. Martin</p>
<blockquote className="review">
A definitive guide to writing code that is both <strong>elegant and maintainable</strong>. Talks about <strong>meaningful naming, reducing dependencies, writing small functions, and avoiding unnecessary complexity</strong>. I will continue to write garbage code though.
</blockquote>

### <span className="book-subtitle">Design Patterns: Elements of Reusable Object-Oriented Software</span>
<div className="book-cover">
  <AsciiCover asset="designpatterns" alt="Design Patterns Cover" variant="portrait" />
</div>
<p className="author">Authors: Erich Gamma, Richard Helm, Ralph Johnson, and John Vlissides</p>
<blockquote className="review">
The <strong>daddy</strong> of all design pattern books. Introduces concepts like <strong>Singleton, Factory, Observer, Decorator, and Command patterns</strong>, which still dominate software architecture today. If you haven't read this, you’ve definitely used its patterns without realizing it.
</blockquote>

### <span className="book-subtitle">The Clean Coder: A Code of Conduct for Professional Programmers</span>
<div className="book-cover">
  <AsciiCover asset="cleancoder" alt="The Clean Coder Cover" variant="portrait" />
</div>
<p className="author">Author: Robert C. Martin</p>
<blockquote className="review">
A call to <strong>professional discipline and ethical behavior</strong>. Talks about saying <strong>"no" when needed, handling deadlines, and taking full responsibility for your work</strong>. More than just a book—it's a mindset shift.
</blockquote>

### <span className="book-subtitle">Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow</span>
<div className="book-cover">
  <AsciiCover asset="hands-on-ml" alt="Hands-On Machine Learning Cover" variant="portrait" />
</div>
<p className="author">Author: Aurelien Geron</p>
<blockquote className="review">
The <strong>Swiss Army knife</strong> for anyone serious about ML. Takes you from <strong>linear regression to transformers</strong> with code you can actually run. Less math-heavy academia, more real-world problem solving. If you work in AI and haven't read this, you're doing it wrong.
</blockquote>

### <span className="book-subtitle">The Staff Engineer's Path</span>
<div className="book-cover">
  <AsciiCover asset="staff-engineer" alt="The Staff Engineer's Path Cover" variant="portrait" />
</div>
<p className="author">Author: Tanya Reilly</p>
<blockquote className="review">
Finally, a book that explains what happens after <strong>senior engineer</strong>. Covers <strong>technical vision, navigating ambiguity, and leading without authority</strong>. Essential reading for anyone who wants to grow without becoming a full-time manager. The chapters on "being glue" hit different.
</blockquote>

### <span className="book-subtitle">Natural Language Processing with Transformers</span>
<div className="book-cover">
  <AsciiCover asset="nlp-transformers" alt="NLP with Transformers Cover" variant="portrait" />
</div>
<p className="author">Authors: Lewis Tunstall, Leandro von Werra, Thomas Wolf</p>
<blockquote className="review">
Written by the <strong>Hugging Face</strong> team themselves. Covers everything from <strong>attention mechanisms to fine-tuning LLMs</strong>. If you're building anything with transformers, this is your bible. The world runs on attention now—might as well understand it.
</blockquote>
