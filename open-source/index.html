Open source

Merged patches in tools I use every day, from terminal emulators to BitTorrent internals.

Most of these started the same way: something I use every day did something odd, I went looking for the reason, and the reason turned out to be fixable. Some are one-line bounds checks. Others meant reading a good part of the codebase before writing a line.

The list below is pulled straight from GitHub, so every entry links to the pull request, the diff and whatever the maintainers said about it.

The ones I'd point to

  • docling #3380

    Speed up layout and table cell matching

    Swapped a scan of every text cell per table cell for an R-tree lookup. Table text matching went from 2.4 s to 0.03 s on the benchmark in the PR.

  • pyscn #695

    Make dependency analysis scale

    Replaced exhaustive path enumeration with one SCC-condensed pass. Django's 908 files now analyze in about 1.2 seconds.

  • calibre #3148

    Protect rooted file paths from traversal

    One shared guard that keeps user-supplied paths inside the library root, used by the content server and extra-file operations.

  • libtorrent #8389

    Fix mmap disk jobs stranded behind fences

    Jobs released by a fence could land on a queue with no threads and stall. Now they route to a live pool or run inline.

  • kitty #10038

    Avoid interpolating SSH login shell paths

    The SSH bootstrap built little Python and Perl programs by pasting paths into them. Now the paths travel as arguments.

  • Mole #905

    Make Trash delete mode fail closed

    If moving to Trash failed, uninstall quietly fell through to permanent deletion. Now it leaves the file alone and says so.

  • fallow #60

    Harden Vue and Nuxt framework edge cases

    My biggest early one: Fallow kept calling live Nuxt and Vue code dead. About 1,100 lines across 44 files to teach it the framework conventions.

  • kitty #10412

    Add an independent DnD copy mode

    I thought hard-linked copies were a bug. They were a deliberate performance choice, so the fix became an opt-in mode instead.

  • libtorrent #8723

    Speed up sparse bitfield refcount updates

    Faster piece-picker bookkeeping when only a few pieces are set. The maintainer benchmarked it and suggested going word-at-a-time next.
